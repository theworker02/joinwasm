# joinwasm

Join HTML/Markdown wasm fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/joinwasm/

## Install / run

```bash
git clone https://github.com/theworker02/joinwasm.git
cd joinwasm
node src/cli.js
node --test
```
